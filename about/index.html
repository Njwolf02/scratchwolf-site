Where these numbers come from

ScratchWolf recounts the unclaimed prizes on every active scratch-off game in 44 states, every morning, straight from each state lottery's own published data. This page explains how that works and what we deliberately do not do.

The data

  • Official sources only. Every figure is read from the state lottery's own published pages or data feeds. Each game page on this site links to the exact source it came from, so you can check any number yourself.
  • Recounted every morning. A full pass runs daily and the footer of every page carries the date it last completed — so if it ever stops, the date visibly stops advancing instead of the site quietly claiming to be current.
  • Measured accuracy. Stored odds were verified against the exact pages the states served, game by game: 99.75% matched, with 35 of 38 checkable states at exactly 100%. The handful that did not match were cases where the source itself published a typo.
  • Gaps are shown as gaps. Some states publish less than others — Tennessee publishes no per-tier odds at all, so we cannot compute an expected value there and we say so rather than inventing one. A missing number is always better than a guessed one.

The model

One machine-learning model runs over the same daily data, retrained every night and validated on data it was not trained on. It exists because a prize count tells you where a game stands today and says nothing about where it is heading.

AI Watch estimates how likely each game is to lose a top prize in the next two weeks, and flags the ones closest to it. Last scored at 0.92 AUC on roughly 187,000 held-out observations, covering all 44 states — including the ones that publish too little for us to compute a ticket's value at all, where it is the only forward-looking signal there is.

It is a watchlist, not a buy list, and that distinction is measured rather than stylistic. Ordering games by this score was tested against three separate measures of whether it produced better picks and never beat plain value ranking; on one it was worse. The model is good at spotting which games are about to lose a jackpot and poor at deciding what to buy, so that is exactly what we use it for.

We also retired a second model rather than keep it running. It ranked games by value minus the risk that value collapsed, and it worked when it was built — until the thing it predicted became rare enough that the adjustment stopped helping, and on its last run it was making the pick slightly worse. Keeping it would have been easy and dishonest.

What it is not: no model here predicts a winning ticket, and none can. See below.

What ScratchWolf is not

  • Not a way to buy tickets. We do not sell tickets, take wagers, or pay prizes. We are an information and education tool built on public data.
  • Not a prediction of a winning ticket — including the models. Scratch-off outcomes are already fixed when the tickets are printed. The models above forecast what happens to a GAME's remaining prize pool, not what is under any particular ticket, and nothing here can tell you that. Every lottery game has a negative expected return over time.
  • Not affiliated with any lottery. No state lottery endorses, reviews or supplies this site beyond what it publishes to the public.

What it actually helps with

Two tickets on the same shelf at the same price can differ a lot in how much prize money is still unclaimed behind them. That is public information, but it is scattered across a different website for every state and changes daily. ScratchWolf collects it, keeps it current, and puts the games side by side so the comparison takes seconds instead of an afternoon.

Who runs it
